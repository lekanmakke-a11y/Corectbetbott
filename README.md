# CorectBet Bot

## Deploy on Railway

1. Fork this repo
2. Create project on Railway
3. Add environment variables:
   - BOT_TOKEN
   - CHANNEL_ID
   - CHANNEL_LINK
4. Deploy

## Environment Variables

| Variable | Description |
|----------|-------------|
| BOT_TOKEN | Bot token from @BotFather |
| CHANNEL_ID | Channel ID (negative number) |
| CHANNEL_LINK | Channel invite link |
